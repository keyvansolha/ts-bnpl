# TS BNPL Digipay

قیمت‌گذاری اقساطی ۴ قسطه و نمایش طرح خرید اعتباری دیجی‌پی در فروشگاه تهران‌اسپیکر.

**English:** Installment pricing and Digipay 4-month plan display for Tehran Speaker online store.

---

## نیازمندی‌ها / Requirements

- WordPress 6.5+
- PHP 7.4+
- WooCommerce 8.0+
- [Amazing theme](https://github.com/webshop-services/amazing-theme) (optional, for tight integration)

---

## نصب / Installation

1. کپی کنید پوشه‌ی `ts-bnpl` را به `wp-content/plugins/`
2. فعال کنید افزونه از پیشخوان ووکامرس
3. برای اعلام سازگاری با HPOS، هیچ کار اضافی لازم نیست

```bash
cp -r ts-bnpl /path/to/wp-content/plugins/
```

## تنظیمات / Configuration

### قیمت‌های اقساطی

**محصولات ← قیمت‌های اقساطی** (Products → Installment Prices)

- جدول همه‌ی محصولات و متغیرهایی که قیمت اقساطی دارند
- ستون‌های نمایش: نام، SKU، قیمت نقدی، قیمت اقساطی، اختلاف
- مرتب‌سازی بر حسب مبلغ اختلاف و درصد
- خروجی CSV برای تطبیق با سیستم حسابداری
- خلاصه‌ی آماری: تعداد، میانگین تفاوت، و محدوده

### نمایش در صفحه‌ی محصول

**محصولات ← قیمت‌های اقساطی** → قسمت "نمایش در صفحه‌ی محصول"

دو حالت نمایش:

#### 1️⃣ حالت بازشونده (Accordion)
- تیزر کم‌رنگ: "امکان خرید ۴ قسطه این کالا از تهران‌اسپیکر"
- کلیک → جزئیات (مبلغ، لوگو، راهنما) همان‌جا باز می‌شود
- پیش‌فرض

#### 2️⃣ حالت پنل راهنما (Modal)
- تیزر کم‌رنگ
- کلیک → پنل راهنما باز می‌شود
- جزئیات طرح بالای بخش "خرید اقساطی چگونه انجام می‌شود"

**تنظیم متن تیزر:** فیلد "متن قابل کلیک"
- خالی = پیش‌فرض: "امکان خرید ۴ قسطه این کالا از تهران‌اسپیکر"

## رابط کاربری / UI

### صفحه‌ی محصول / Product Page

**قیمت نقدی همیشه CTA اصلی می‌ماند.**

خرید اعتباری یک گزینه‌ی ثانویه و جمع:
- تا کاربر کلیک نکند، مبلغ قسط و نام دیجی‌پی دیده نمی‌شود
- موبایل و دسکتاپ با طراحی تطبیقی پشتیبانی می‌شوند

**متغیرهای متحرک:** با تعویض رنگ/ویژگی:
- مبلغ قسط به‌روز می‌شود
- در حالت مودال، جزئیات در داخل پنل جایی دارد

### تسویه‌حساب / Checkout

- درگاه دیجی‌پی وقتی فعال است، نمایش دارد
- انتخاب درگاه → مبالغ بازمحاسبه می‌شود
- کیف پول جزئی خودکار غیرفعال می‌شود تا تضاد مبالغ رخ ندهد

## توسعه / Development

### بازنویسی تنظیمات

برای override حالت یا متن تیزر در کد:

```php
// تغییر حالت جهانی
add_filter( 'ts_bnpl_display_mode', function () {
    return 'modal'; // یا 'accordion'
} );

// تغییر متن تیزر
add_filter( 'ts_bnpl_teaser_text', function () {
    return 'خرید اقساطی دسترس‌پذیر است';
} );
```

### قیمت اقساطی محصول

```php
// دریافت
$teaser_html = TS_BNPL_Display::teaser_html( $total );

// در variation:
$variation['bnpl_html'] = TS_BNPL_Display::teaser_html( $total );
```

### داده‌های متادیتا

- **محصول:** `_bnpl_price` (قیمت اقساطی)
- **سفارش:** `_is_bnpl` (آیا اقساط است)
- **سفارش:** `_bnpl_months` (تعداد اقساط، مثلاً ۴)
